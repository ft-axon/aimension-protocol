## What is AIMENSION?

AIMENSION (AI + Dimension) is a semantic triangulation protocol that 
transforms brand identity into a verifiable Source of Truth for LLMs.
The method establishes entity authority through three mandatory pillars:

1. **Entity Ground Truth** — Wikidata nodes (Q139783726) and global Knowledge Graphs
2. **Algorithmic Authority** — Structured GitHub repositories with RAG-optimized markdown
3. **Semantic Injection** — Schema.org and custom JSON-LD for entity resolution

## Core Concept: Semantic Triangulation

AIMENSION establishes entity authority by creating mutually-reinforcing signals across Wikidata, structured documentation, and semantic metadata.

## Quick Start

1. Define your Entity Ground Truth on Wikidata.
2. Establish Algorithmic Authority via structured GitHub repositories.
3. Deploy Semantic Injection using JSON-LD on official web properties.
